## โลโก้และความหมาย

- **Canva หน้า 1:** โลโก้โคลเวอร์สี่กลีบรูปหัวใจ พื้นขาว: น้ำเงินด้านบน เขียวด้านขวา ส้มแดงด้านล่าง เหลืองด้านซ้าย มี W / L สีขาว, World Lab, since, 2026 และเส้นรัศมีวาดมือ
- **หน้า 2:** ภาพโคลเวอร์สี่สี ไม่มีตัวอักษร ใช้เป็นหลักฐาน visual motif
- **หน้า 3:** แผนผังห้าแนวคิด: System ด้านบน, Logic ซ้าย, Inner World กลาง, Growth ขวา, Com. ด้านล่าง
- **หน้า 4:** ตัวอย่างการใช้โคลเวอร์คู่กับจุดสี ไม่ใช่ template ของทุกหน้าจอ

**v2:** ใช้ PNG หน้า 1 จาก Canva ตรง ๆ ใน `assets/world-lab-logo.png` แทนเครื่องหมายดาวที่เคยใช้ ไม่วาดใหม่ ไม่หมุน สลับตำแหน่งสี ยืดสัดส่วน หรือเปลี่ยนสีในโลโก้ ภาพ local ชื่อ “World Lab - Final Logo (1).png” มีรูปแบบตรงกัน แต่ใช้ export ปัจจุบันจาก Canva เป็นหลัก

**ดัดแปลงสำหรับ v2:** โลโก้ header 64px desktop / 52px mobile บนพื้นขาว มีช่องว่างและชื่อ World Lab ข้าง ๆ เพื่ออ่านได้เมื่อรายละเอียดในโลโก้เล็กลง ขนาดเหล่านี้เป็นค่าหน้าจอของ v2 ไม่ใช่ minimum size ทางการ

## สีและ semantic mapping

สีด้านล่างอ่านจากพื้นที่สีทึบของ PNG **Canva หน้า 3** และสอดคล้องกับ source เว็บปัจจุบัน โลโก้เป็นภาพมี texture จึงไม่ควรดูดสีจากขอบ/gradient แล้วตั้งเป็นค่าใหม่

| ความหมาย | สี Canva | ตัวอย่างใช้ใน v2 |
| --- | --- | --- |
| System Lab | `#456DD0` น้ำเงิน | ป้าย System, ภาพระบบ/เครื่องมือ; focus และ calendar ใช้เป็น accent ดิจิทัล |
| Growth Lab | `#669F65` เขียว | ป้าย Growth, งานสร้างสรรค์/ลงมือทำ |
| Communication / Com. Lab | `#F8642F` ส้มแดง | ป้าย Com., ภาษาและการสื่อสาร |
| Logic Lab | `#FFC53B` เหลือง | ป้าย Logic, คณิตศาสตร์และการคิดอย่างมีเหตุผล |
| Inner World | `#D9D9D9` เทาอ่อน | โลกข้างใน/สะท้อนตัวเอง; ไม่ตั้งสถานะการประเมินเด็กจากสีนี้ |

**ความต่างจาก repo เก่า:** green `#4E8B61`, yellow `#F5B731`, orange `#E8522A`, blue `#4A6FD4`, grey `#9A9A9A` เป็น variant ที่ source dashboard เดิมใช้จริง แต่ v2 เลือก **Canva หน้า 3 เป็นค่าหลัก** ไม่อ้างว่า variant เดิมผิด ไม่แก้เว็บเก่า

**สีใช้งานดิจิทัล:** repo เดิมมี background `#F5F2ED`, panel `#FFFFFF`, text `#2A2A2A`, border `#DDD9D2` จึงนำมาใช้ต่อ พร้อมสีอ่อนสำหรับภาพ/การ์ด เป็น **adaptation** ไม่ใช่สีแบรนด์เพิ่ม

อย่าใช้สีเป็นข้อมูลเพียงอย่างเดียว ใส่ภาพและชื่อด้วย สีแบรนด์สดใช้เป็นวงกลม ขอบ หรือพื้นอ่อน ข้อความเล็กใช้สีเข้ม โดยเฉพาะบนเหลือง เขียว และส้ม เพราะตัวหนังสือขาวในอาร์ตต้นฉบับไม่ใช่หลักประกัน contrast สำหรับ UI ทุกขนาด ตัวอย่าง: ป้าย Logic พื้นเหลือง + ตัวอักษรเข้ม, System น้ำเงิน + ขาว; หลีกเลี่ยงข้อความเหลืองบนขาว

## Typography และน้ำเสียง

**พบใน repo:** Sanchez สำหรับ brand/English display, DM Sans สำหรับ body อังกฤษ, Noto Sans Thai สำหรับไทย, Noto Sans SC เป็น fallback จีน เว็บ worldlab.club โหลด Sanchez เช่นกัน Canva แสดงตัวอักษร serif แต่ไม่มี typography specification แยกครบทุกภาษาในสี่หน้าที่ตรวจ

**v2:** self-host Sanchez 400, DM Sans 400/600/700 และ Noto Sans Thai 400/600/700 พร้อม SIL OFL; ไม่เรียก Google Fonts ตอนใช้งาน ใช้ Sanchez กับ wordmark/English eyebrow และเวลา ใช้ DM Sans + Noto Sans Thai กับข้อความไทย–อังกฤษที่ต้องอ่านเร็ว ไม่ใช้ตัวบาง/ตัวเล็กเพื่อความสวยจนอ่านยาก

- ตัวอย่างน้ำเสียงจากเว็บ: **Learn. Build. Explore.**
- คำว่า **learning space** อธิบายบริบทการเรียนรู้; ไม่ทำให้คำว่า homeschool เป็น tagline หลักของ v2
- คำไทยสั้น ๆ เช่น “สื่อสาร”, “ระบบ”, “คิดเป็น”, “เติบโต”, “โลกข้างใน” เป็นคำช่วยเด็กอ่านใน v2 ไม่ใช่ชื่อไทยทางการที่ Canvaกำหนด

## Cards, spacing และภาพเป็นหลัก

**พบใน repo:** widget grid 3 คอลัมน์พร้อม span, gap 16px, card radius 8/14/20/28px, แผงขาวและเงาอ่อน, content width 1280px, hero/date card padding ประมาณ 22–28px

**ดัดแปลงสำหรับ v2:** สเกลช่องว่างประมาณ 8/16/24/32px, panel radius 20px, ปุ่ม/field ประมาณ 12–14px, card padding 20–28px desktop และ 16–20px mobile พื้นสงบและพื้นที่ว่างช่วยให้ภาพสำคัญเด่นขึ้น ไม่เติม texture โคลเวอร์ไว้ทุกพื้นที่จนรก

- เริ่มจาก **ภาพที่รู้จัก + คำสั้น + ตอนนี้/ถัดไป**: หนังสือ = อ่าน, ลูกคิด = ตัวเลข, ต้นไม้ = ปลูก ไม่ต้องให้เด็กอ่านข้อความอธิบายยาวเพื่อเข้าใจการ์ด
- รูปประกอบ SVG ที่สร้างในแอปเป็น adaptation สำหรับ widget ไม่ใช่โลโก้ทางการ
- ชื่อ/เวลา/สถานะหลักอยู่หน้า card; ที่มาและสิ่งที่ยังไม่ยืนยันเปิดดูใน details ได้ เพื่อให้ผู้ปกครองตรวจหลักฐานโดยไม่ทำให้หน้าหลักเต็มไปด้วยข้อความ
- อย่าใช้ภาพโปรเจคสวย ๆ แล้วใส่เปอร์เซ็นต์ความคืบหน้าที่ไม่มีหลักฐาน ไม่ยืนยันตาราง ≠ เด็กว่าง; ให้ระบุ “รอยืนยันตาราง”

## Responsive และ accessibility

ค่าต่อไปนี้เป็น **ข้อกำหนดใช้งาน v2** ไม่ใช่กฎ Canva: desktop แสดง panel คู่และการ์ดหลายคอลัมน์; mobile เรียงหนึ่งคอลัมน์และใช้ภาพด้านข้าง ให้ภาพ/ชื่อยังอ่านได้ที่ 320–390px ตรวจ tablet ราว 820px และ desktop จริงด้วย

ใช้ contrast ตัวอักษรปกติอย่างน้อย 4.5:1, ข้อความไม่เล็กเกินอ่านง่าย, ปุ่มหลักอย่างน้อย 44px, focus ring, label ไทย, ปุ่มที่มีชื่อ, keyboard/ESC สำหรับ dialog, reduced motion, alt สำหรับภาพสำคัญ และ aria-hidden สำหรับภาพตกแต่ง ห้ามใช้สีเพียงอย่างเดียวบอกวันสอบ/เสร็จแล้ว

## ตัวอย่างและขอบเขต

- **Header:** โลโก้ Canva เต็มบนขาว + World Lab/Sanchez + Learn. Build. Explore.
- **Logic resource:** รูปลูกคิดบนเหลืองอ่อน + ชื่อสั้น + ปุ่มเปิดลิงก์ ไม่อ้างว่าเด็กลงทะเบียนหรือเรียนจบแล้ว
- **Calendar:** วันสำคัญมี marker + icon + ชื่อประเภท; รายละเอียดแหล่งข้อมูลเปิดดูได้
- **Growth project:** ภาพงานจริงที่ได้รับอนุญาต + สถานะที่ยืนยันเท่านั้น
- **Inner World:** ป้ายเทาอ่อนและคำอธิบายสุภาพ ไม่สร้างคะแนนหรือสรุปสภาวะเด็กโดยอนุมาน

คู่มือนี้สังเคราะห์ Canva + source งานเดิมเพื่อใช้จริง ไม่มีการแก้ Canva ต้นฉบับ เปลี่ยนสิทธิ์การเข้าถึง หรืออ้างว่าเป็นคู่มือ CI ทางการฉบับสมบูรณ์ ข้อมูลการเรียนที่เผยแพร่ต้องอยู่ในขอบเขตที่ผู้ปกครองอนุญาตเท่านั้น
