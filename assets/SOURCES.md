# Brand assets

- `world-lab-logo.png`: exact, unmodified PNG export of page 1 of the user-supplied Canva **World Lab - Final Logo** design (`DAHC_mR0Hy8`), downloaded after all four pages were inspected on 2026-10-14. No logo was redrawn, recolored, cropped or regenerated. The existing local “World Lab - Final Logo (1).png” was inspected as corroboration; the current Canva export takes priority.
- `fonts/`: Sanchez Regular, DM Sans 400/600/700, Noto Sans Thai 400/600/700, downloaded from the official Google Fonts CSS API and fonts.gstatic.com on 2026-10-14. All are self-hosted; no runtime Google Fonts connection is made. Their SIL Open Font Licenses from google/fonts are included alongside the files.
- Canva page 3 solid circles provide the semantic palette: System `#456DD0`, Growth `#669F65`, Communication `#F8642F`, Logic `#FFC53B`, Inner World `#D9D9D9`. Values were verified from the exported page's solid pixels, not estimated from screen colors.
- Dashboard illustrations in `art.js` remain original native SVG drawings; they are an implementation adaptation, not official World Lab logo assets.
